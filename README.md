# Budget Calculator

This is a web app that can calculate your budget like for grocery or shopping list. This is a no build static site so I only use CDN for my tech stacks. I use Tailwind CSS, DaisyUI, Font Awesome, Preact, HTM, and Dexie. If you want to try this project locally, you have to serve the project using `npx serve` command in terminal with nodejs. You can't directly open and run the index.html.

I made this project to try Preact and checking if this is better than Vue CDN. So far, I like this more because the code is more readable than Vue's syntax. Even though I could write the code in JSX-like syntax, the string html is still a problem...
